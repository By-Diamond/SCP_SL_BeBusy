# SCP:SL BeBusy 

**死了自动放歌，活了自动暂停。** 想让它干点别的，也能自己加。

玩 SCP:SL 总有些顾不过来的时刻：一死就该切出去看看别的，一活又得赶紧回来。
这个程序在后台盯着游戏日志，你一死、一活，它立刻执行你安排好的动作 ——
默认是「**死了播放音乐、活了暂停音乐**」。

**它不是外挂**：只读游戏自己写的日志，**不注入、不挂钩、不读内存、不改游戏本体**
（唯一会发出"真实输入"的，是你自己配的「模拟按键」，见下文）。

## 使用方法

1. **双击运行** —— 只有右下角托盘多一个圆点图标，不弹窗、不打扰。
2. **右键图标 → 显示界面 → 功能配置** —— 往「死亡后」「复活后」两个框里加你想执行的操作。
3. **进游戏照常玩** —— 托盘图标**绿 = 活着，红 = 死了 / 观察者**。

## 能做什么

「死亡后」「复活后」各是一个列表，**从上到下依次执行**；某一条失败只记一笔日志，不影响后面的
（除非中途又死了 / 又活了 —— 那会**当场打断**这条列表，见下面「几个要紧的说明」）。

| 操作 | 要填什么 | 常见用法 |
|---|---|---|
| 媒体播放 / 媒体暂停 | — | 默认：死了放歌、活了暂停 |
| 打开网页 | 网址 | 死了顺手开一下直播 / 攻略 |
| 切换到游戏界面 | — | 复活了把游戏窗口拉到最前 |
| 游戏最小化 | — | 死了把游戏收起来 |
| 切换到界面 | 窗口 | 死了切到别的应用(抖音等) |
| 最小化界面 | 窗口 | 死了把某个窗口最小化 |
| 执行文件 | 文件 | 死了像**双击**一样打开某个文件 / 快捷方式 |
| 调节程序音量 | 进程名 + 目标音量 + 渐变 | 死了把游戏调静音，活了恢复 |
| 语音播报 | 播报文本 / 音乐 + **提示音音量 / 语音音量**可调 | 死了听见「你已死亡」，也可先放一段提示音 |
| 发送通知 | 标题 + 内容 | 死了弹个系统通知 |
| 延迟执行 | 毫秒（0-10000） | 先等几秒，再往下做 |
| 模拟按键 | 按键 | 死了按下某个键（播放音乐，保存即时重放等） |

* 每个操作**一个窗口填完**：一个参数一个控件（文本 / 文件带「浏览…」/ 网址 / 窗口下拉 / 进程下拉 /
  数字框 / 只读按键框）；填错**就地提示、不关窗口**，改完再点「确定」。
* 「窗口」下拉列出**当前开着的窗口**（值是进程名，鼠标悬停看标题），「进程名」下拉只列
  **现在有声音的程序**（有音频会话的才调得动音量）；两个都能**刷新**、也都能**手打**。
* 「打开网页」「切换到界面」「最小化界面」「执行文件」「调节程序音量」「语音播报」「发送通知」
  「延迟执行」「模拟按键」**可以放多条**；其余每种同框最多一条
  （「媒体播放」放两条的话，等于放完立刻又暂停）。
* 同一个操作可以**同时**出现在「死亡后」和「复活后」两个框里（典型用法：死了切走、活了切回来）。

### 几个要紧的说明

* **两个列表互不重叠**：死亡 / 复活**共用一条执行线**。新的死亡（或复活）一来，正在跑的那条列表
  会**当场打断**，后面的操作不再执行 —— 日志里会写明「第几条起不再执行」，被打断的那条记 `⏹`，**不算成功**。
  语音播报同时「停声 + 清空排队」，绝不会两条声音叠在一起。
* **死亡判定时间**：默认 **700ms**（死了又马上复活就当没死），在**设置页**可改 **500-10000ms**，改完立即生效。
* **调节程序音量**只改**这一个程序自己**的音频会话，**不动系统总音量**、不动别的程序。
  进程名就填 `SCPSL.exe` 这种；程序没开、或它现在没在出声，就找不到会话（日志里如实写「没找到」）。
  目标音量和当前一样时**直接跳过**（不白改）。
  **渐变在后台自己跑完**：操作立刻返回、不挡后面的操作，日志写真实起止；
  同一个程序再来一次渐变，**新的接管旧的**；程序退出时会把没跑完的渐变停掉。
* **语音播报**：提示音交给**系统播放器**放（mp3 / m4a / wav / flac 都能放，扩展名不对也没关系），
  代价是起播慢约半秒；**提示音音量**和**语音音量**各管各的，谁也不影响谁。
  文本用 Windows 自带语音引擎朗读（有没有中文嗓音取决于你系统装了什么）。
* **发送通知**发完会**核对**通知中心的条数：进去了才说「已进通知中心」，没进去就老实报 ⚠。
  游戏**全屏**时 Windows 可能压掉横幅（系统行为），这时去 `Win+A` 通知中心看。
  通知里显示成「SCP:SL BeBusy」+ 图标，需要一条当前用户的注册表项
  （`HKCU\Software\Classes\AppUserModelId\SCP_SL_BeBusy`，程序自己写，删掉也不影响其他功能）。
* **模拟按键**发的是**真实按键事件**，会发给**当时最前面的窗口**（可能是游戏，也可能不是）——
  也就是说它**真能按进游戏**。用哪个键、要不要用，你自己定。
  能录**组合键**（`Ctrl+Shift+D`）、**方向键**（`↑↓←→`）、**回车**、`Esc`、**Win**（单独按一下也行）；
  在按键框里 **`Esc` = 清空**（不是关窗口），**回车会被当成按键**（不会变成「点确定」）。
  **锁屏时、或者前台窗口是"管理员权限"运行的程序时，Windows 会拒绝**（日志会写「只收下 0/N 条」+ 错误码），
  这是系统在拦，不是程序没做事。

## 常见问题

**Q：加了操作却好像没反应？**
界面改动是**立即生效**的（没有保存按钮）。真没动静就看「**日志**」页，每条操作的结果都在上面。

**Q：媒体键没控住我的播放器？**
Windows 的播放/暂停键是**盲发**的：系统不告诉程序「现在是播放还是暂停」，也只有当前的默认播放器认这个键。
所以状态栏那栏显示的是**程序最后把它改成了什么样**，键没送出去就老实退回「未知」。
你自己手动按过播放/暂停之后，用托盘菜单的**手动：媒体播放 / 暂停**对一下就行。

**Q：偶尔死了一会儿才动作，或者该动的时候没动？**
复活判定用的参数我还在拿公共服的日志微调，波次复活偶尔会晚一拍。遇到就把**那一段日志**发我。

**Q：音量调了没反应？**
只有「进程名」对得上、而且**它现在正在出声**时才找得到它的音频会话；另外这个操作只改**它自己**那一路音量，
不改系统总音量。日志里会写明是「本来就一样，跳过」「没找到」还是「调好了」。
带**渐变**的时候操作会**立刻返回**，然后日志里会写「开始渐变」和「渐变完毕」两行 —— 看到第二行才算走完。

**Q：提示音放不出来？**
提示音是交给**系统播放器**放的，所以 mp3 / m4a / wav / flac 都能放，**扩展名写错也没关系**（看内容不看后缀）。
如果日志写「放不了这个音频文件」，把系统给的原因一并发我。另外因为要起一个系统播放器进程，
从「触发」到**听见声音**大约有半秒延迟。

**Q：通知没弹出来？**
程序发完会**核对**通知中心里有没有多出这条：进去了日志写「已进通知中心」，没进去就报 ⚠。
游戏**全屏**时 Windows 会压掉横幅（系统行为，不是程序没发），按 `Win+A` 到通知中心能看到。

**Q：模拟按键没反应 / 收不到我要的键？**
先在**按键框**里直接按你要的键（框是只读的，按一下就记下来）：组合键、方向键、回车、`Esc`、`Win` 都支持；
在框里 `Esc` = **清空**（不是关窗口）、回车会被当成按键（不会变成「点确定」）。
执行时锁屏、或前台窗口是"管理员权限"的程序，Windows 会拒绝合成按键（日志会写错误码 5）。

**Q：模拟按键算不算作弊？**
它发出去的和你自己按键盘没有区别，也只看**当时最前面的窗口是谁**。程序本身不注入、不挂钩、不读内存、
不改游戏文件，按键是你自己配的 —— 但它确实是"真的在按"，会不会被你进的服判定成异常，我没法替你保证，
用不用自己权衡。

**Q：游戏没开能用吗？**
游戏没开就什么都判定不到（它只读日志），但程序不会报错，也不会乱动你的电脑。

**Q：需要管理员权限吗？**
不需要。开机自启动只写你自己账户的注册表项（任务管理器「启动」里能看到、能关）；
通知显示名同理，写的是 `HKCU\Software\Classes\AppUserModelId\SCP_SL_BeBusy`（当前用户，可删）。

**Q：会被当成外挂吗？**
不注入游戏、不挂钩、不读内存、不改游戏文件，只是读一份游戏自己写的日志文本；
其它动作（放歌、切窗口、开网页、开文件）都是你**自己配**的，程序不会自己去下载或运行任何东西。

## 安装 / 运行

* **直接下载 exe**：见 [Releases](https://github.com/By-Diamond/SCP_SL_BeBusy/releases)。还没传就用下面的办法自己打一个。
* **从源码跑**（Python 3.9+）：`pip install -r requirements.txt`，然后 `pythonw scpsl_auto_player.py`
* **打成单文件 exe**：Windows 上双击 `build.bat`，出 `dist\SCP_SL_BeBusy.exe`

> 「调节程序音量」「语音播报」靠 `pycaw` + `comtypes`（Windows 的音频会话接口 + 语音引擎），
> 已经在 `requirements.txt` 里，`build.bat` 也会自动打进 exe。
> 系统通知和**提示音播放**走 PowerShell / WinRT / 系统播放器，不需要额外装东西。

首次运行会在程序所在目录（便携）生成 `settings.json`（你的配置）、`SCP_SL_BeBusy.log`（运行日志）、
`state_log.csv`（每次判定的留痕）；目录不可写时自动改用 `%APPDATA%\SCP_SL_BeBusy`，
想换位置在**设置页**里迁移，**旧文件不会删**。
